# AI 短剧工作室管理平台产品设计

平台面向短剧制作人员。用户输入一个短剧 Idea 即可创建项目，随后可以查看制作进度、定位运行或超时的任务，以及查找生成的素材和分集交付物。一个项目可能包含数十集、每集数十个镜头。工作台默认呈现当前在做的工作，用户可以进入具体任务或扩大素材搜索范围。

## 工作台布局

| 位置 | 内容与操作 |
| --- | --- |
| 左栏 | 项目列表。每项显示项目名称、状态和完成百分比。点击项目切换中栏和素材库，点击「＋ 新建」打开创建弹窗。 |
| 中栏 | 上方显示选中项目的名称、状态、进度和暂停／继续。下方显示任务树、任务详情和画布操作。 |
| 右栏 | 选中项目的素材库。支持范围筛选、搜索、预览和查看版本，也可展开浏览。 |
| 顶栏右侧 | 切换明亮二次元与深色工作台主题。 |

### 创建与控制项目

- 创建弹窗包含一个多行 Idea 输入框、「创建项目」按钮和右上角关闭按钮。关闭后再次打开弹窗，保留未提交的输入。创建成功后自动选中新项目，系统同时创建状态为「等待」的「短剧制作」根任务。
- 项目有「运行中」「已暂停」「已完成」三种状态。超时任务数量作为补充提示。项目完成后隐藏暂停／继续按钮。
- 「暂停」停止派发新任务，已经运行的任务继续收尾。收尾期间，进度、任务状态和素材库照常更新。「继续」恢复派发满足条件的任务。
- 项目只展示一个由任务驱动的完成百分比。每个任务的直属子任务等权，创建时固定子任务总数，进度递归取平均。叶子任务未完成为 0，完成为 1。进度表示任务结构的完成比例，项目状态仍以根任务状态为准。

## 生产流程

「短剧制作」依次编排全剧规划、全局关键素材生成、全部剧集制作。全剧规划产出世界观、人物设定、分集大纲和全局关键素材清单。全局人物、场景和道具可以并行生成，全部所需素材就绪后才开始制作剧集。剧集按集序一次派发一集，本集交付完成后进入下一集。全部剧集交付后，根任务完成。

| 单集阶段 | 完成条件或产出 |
| --- | --- |
| 制作分集剧本 | 按本集大纲生成完整剧本。 |
| 分集剧本结构化 | 得到有序分镜，记录场景、画面动作、对白、音效需求与预计时长，提取本集新增人物、场景和道具。 |
| 分集关键素材制作 | 复用已就绪的素材，并行补齐所需人物、场景和道具。 |
| 制作分集全部分镜图 | 并行生成各镜分镜图，确定采用版本，等全部分镜图就绪后进入音视频阶段。 |
| 制作所有分镜 | 获取本集分镜列表，并行创建「制作分镜」子任务。所有分镜完成后进入剪辑与合成。 |
| 剪辑与合成 | 所需画面和音频齐备后，按镜头顺序粗剪、对齐对白与音效，再处理节奏、字幕、转场、混音和片头片尾。交付成片、字幕和可编辑时间轴。 |

每个「制作分镜」先创建「制作分镜对话音频」子任务，根据 `dialogue` 调用「制作音频 n8n 工作流」。无输入对话时仍创建该任务，直接完成且不调用工作流。对话音频任务完成后，再并行创建「制作分镜视频」与「制作分镜音效」子任务；音效根据 `sound` 调用同一条「制作音频 n8n 工作流」。视频与音效全部完成后，本分镜完成。各分镜独立推进，视频采用实际配音指导时长，无对白时采用预计时长。

单镜头视频以本镜采用的分镜图作首帧。当下一镜属于同一场景时，以它采用的分镜图作尾帧。跨场景和本集末镜的尾帧留空。口型驱动镜头引用最终配音，合成沿用同一版本，字幕依据最终配音时间戳对齐。如果更换了口型驱动配音，受影响的镜头需要重新生成，并同步更新时间轴和字幕。完整生产规则见 [生产流程](production-flow.md)，调度规则见 [技术方案](technical-design.md)。

## 任务树

任务树以「短剧制作」为根，连线表示任务的创建关系。任务详情呈现实际执行依赖，例如「镜头 23 视频等待本镜配音」。

### 默认运行路径

只绘制所有运行任务到根节点的路径。多个运行任务共享的祖先仅出现一次，路径上的祖先保留自己的任务状态。没有运行任务时，画布保留根节点。支持拖动画布、缩放和一键适应当前视图。「定位运行」与「定位超时」用于跳到对应节点，超时任务不在当前视图时打开其所在子树。

### 节点样式与交互

| 状态 | 圆点样式 |
| --- | --- |
| 等待 | 灰色圆点 |
| 运行 | 蓝色实心圆，外侧有缓慢旋转的蓝色弧线 |
| 超时 | 橙色圆点 |
| 完成 | 绿色圆点 |

画布保留状态图例。节点默认只显示圆点，鼠标悬停或键盘聚焦时在节点旁显示任务名称。任务详情以文字显示状态。启用系统的减少动态效果设置时，运行弧线保持静态。

| 操作 | 结果 |
| --- | --- |
| 单击节点 | 打开任务详情，显示任务名称、状态及可用的等待原因或超时说明。存在可查看产出时显示「查看 N 个产出」。任务因失败被阻塞或已超时时显示「重试」按钮。右栏保持原样。 |
| 双击节点 | 以该节点为根展示子树，最多显示直接子任务与孙任务。两层内的四种状态均可见。 |
| 点击子树根节点上方的竖线或「返回」 | 返回上一级视图并恢复原画布视角。连续下钻时逐级返回，默认运行路径没有返回竖线。 |

用户停留在一棵子树时，任务状态更新保留所在层级和当前视角。详情卡避开被选中的圆点，便于连续下钻。

## 素材库

### 按范围浏览和筛选

右栏有当前制作集时默认展示该集。用户可选择「全剧共用」「全项目」或指定剧集。同一范围内可以组合使用素材类型、镜头和名称搜索。点击「展开」进入大视图，沿用当前范围和筛选条件。

| 类型入口 | 包含内容 |
| --- | --- |
| 剧本 | 全剧规划中的文本产物、分集大纲、分集剧本。 |
| 角色、场景与道具 | 人物设定、场景参考和关键道具，包含全剧共用与单集新增素材。 |
| 分镜 | 各镜头的分镜图及其版本。 |
| 音频 | 台词配音、旁白、环境音、动作音效和配乐。 |
| 视频 | 镜头视频、粗剪和分集成片。 |
| 交付 | 按集查找成片、字幕与可编辑时间轴。成片也可从「视频」找到。 |

「全部」展示当前范围内所有类型。「交付」是用于收齐分集交付物的入口。一份素材的多个生成版本归在同一张卡片下，可展开查看历史版本。被下游采用的版本显示「已采用」。重跑产生新的候选版本，已采用的版本继续供引用它的任务使用。

### 从任务查看产出

1. 用户在任务详情点击「查看 N 个产出」。右栏进入该任务的产出视图，标明任务名称，显示该任务实际生成的全部素材和确切版本。
2. 产出可以横跨类型与集数。进入时暂时收起日常筛选，所以同一镜头的两个产出版本也能同时看到。
3. 用户点击「返回素材库」，右栏恢复原来的范围、类型、镜头、搜索词和滚动位置。中栏保留浏览位置。

## 主题

默认使用明亮二次元主题，采用暖白底、淡薰衣草和蓝色点缀，分镜预览可呈现插画风格。右上角可切换深色工作台。两种主题的状态色含义一致。平台记住用户的主题选择，切换时保留所选项目、画布视角与素材筛选。

## 版本范围与待确认项

- 人工审核确认留到后续版本。本版流程在任务依赖满足后自动推进。
- 偶发失败和超时由系统按次数自动重试，用尽后才需要人工点击「重试」。已完成任务的重跑与更换配音留到后续版本。
- 任务树首版采用运行路径和两层下钻。批量任务操作与更复杂的分组交互留待实际使用反馈。
- **已确认进度规则。** 创建任务时固定直属子任务总数，每个权重为 1；尚未创建的位置贡献为 0，无需执行的任务直接完成。父任务进度递归取平均，项目采用根任务进度。全部子任务完成而父任务仍在收尾时，可显示 100% 及当前运行状态，交付与后续派发仍以完成状态为准。

## 产品验收用例

| 场景 | 预期结果 |
| --- | --- |
| 输入 Idea，关闭弹窗后重新打开，再提交 | 输入保留。创建后自动选中新项目，并能定位「短剧制作」根节点。 |
| 在任务运行中暂停，再继续 | 已运行任务可以完成并登记产出，等待的下游任务保持等待。继续后才派发满足条件的任务。 |
| 两个运行节点共用一段祖先路径 | 画布只画两条运行路径，共享祖先仅出现一次。所有运行任务结束后，默认视图保留根节点。 |
| 运行节点悬停、单击、双击 | 悬停显示任务名，运行节点的弧线在转动。单击打开详情，双击展开到孙任务，且详情卡不会截获双击。 |
| 连续进入两层子树，点击根节点上方的返回竖线 | 每次返回一级并恢复该级视角。回到运行路径后，返回竖线隐藏。 |
| 当前集已设置镜头和关键词筛选，打开一个跨范围且有多个版本的任务产出 | 显示该任务全部实际产出及对应版本。返回后恢复范围、筛选和滚动位置。 |
| 打开超时或因失败被阻塞的任务详情，点击「重试」 | 任务回到等待并重新派发，详情显示新的执行；正常等待、运行或完成的任务不显示「重试」。 |
| 在某集选择「交付」 | 同时找得到该集的成片、字幕与可编辑时间轴。 |
| 在子树内切换主题，再重新打开页面 | 切换时项目、画布和素材筛选保持原位。重新打开后记住所选主题。 |

交互见 [浏览器原型](../prototype/index.html)。原型使用演示数据。
