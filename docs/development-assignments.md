# 首版开发分工

本台账由协作协调者维护。按任务给执行会话提供角色、目标、范围、依赖、验收标准和 Git 基线。

| 席位 | 任务包 | 范围 |
| --- | --- | --- |
| CTO | T01 | Codex 负责通用调度核心、任务类协议与恢复重试 |
| 生产后端 | T02 | 短剧生产任务类、生产数据与叶子任务契约 |
| 平台接入 | T03、T04 | n8n 执行接入、内部契约、素材存储与交付登记 |
| 工作台 | T05、T06 | 一个 Claude Code 会话负责公开 API、Admin 与 React 工作台，维护公开契约和前端类型 |
| 专业 Agent | T07 | 角色运行服务、配置版本与专业角色接入 |
| n8n 工作流 | T08 | 八条生产工作流与联调样例 |
| 渲染与集成 | T09、T10 | 独立的 Claude Code 会话负责 T09 时间轴和 FFmpeg 渲染。集成与合并负责人（T10）负责 PR 巡检、合并、联调和验收 |

Codex 会话和 Claude Code 会话的任务编号、会话 ID、worktree 路径及最近提交保存在协调者的本地交接记录。重启后可在对应 worktree 用 `claude --resume <会话 ID>` 接续 Claude Code，并用 Git 核对代码进度。
